# Homepage brand scroll assembly

The supplied text-scroll-animation CharacterV3 effect replaces the rolling homepage logo row. Seven original local logos fan inward with scroll-linked translation, rotation and scale. Brand links and KOPAT's original distributor badge remain readable in stable grid cells. The two brands without original logos remain available through View all.

Uses the existing motion/react dependency, native scrolling and components/ui structure. No duplicate animation package or global scroll interception is needed. Reduced-motion and server-rendered/no-JavaScript visitors see a static grid. Images remain contained and responsive.
