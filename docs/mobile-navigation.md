# Mobile navigation

At viewport widths up to 650px, the header uses a three-line Menu disclosure instead of the full navigation row. Desktop navigation retains its existing Home, Products, Brands, Company and Contact links and dropdowns.

The mobile navigation uses native details/summary controls so opening the menu and browsing Products/Brands works without JavaScript. With JavaScript, tapping outside closes the menu, selecting a link closes it, and Escape closes a submenu before the outer menu while returning focus to its summary. Its panel scrolls within the viewport for long category lists. It adds no animation or JavaScript dependency for access to links.

Validation: static build and 406-route SEO audit passed; five-width homepage browser checks verify mobile open/close, nested Brands, outside click, Escape focus handling, desktop navigation and no-JavaScript product navigation.
