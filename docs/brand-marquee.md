# Homepage horizontal brand scrolling

Explore our brands now scrolls the existing seven genuine logo tiles from right to left in a continuous rolling loop. Original brand URLs, names, images and KOPAT's recorded distributor note remain unchanged; no substitute logos are added for brands without one. A duplicate group allows a seamless loop without duplicate keyboard stops or screen-reader announcements. Its links remain clickable with a mouse/touch when that copy rolls into view, but are hidden from assistive technology and removed from the tab order.

The animation starts after hydration and respects the system reduced-motion preference. Without JavaScript or with reduced motion, all seven brands appear in an ordinary responsive grid. Hover pauses motion. Focusing a logo restores the complete still grid so keyboard users can reach every link safely. The visible pause/resume button was removed at the client’s request. Desktop and mobile use the same horizontal rolling strip with consistent logo tiles. The still fallback uses two columns on mobile, four on tablet and seven on desktop.

The homepage browser checks verify actual movement, hover pause, keyboard behavior, reduced motion, no-JavaScript brand links and responsive overflow. Screenshots are in artifacts/brand-marquee/.

KOPAT's source-backed “Official Distributors in the Gulf” note is highlighted with a dark copper badge and white text in the homepage logo tile, brand directory and KOPAT archive. No distributor claims are added to other brands. The badge uses the primary copper palette with readable contrast.
