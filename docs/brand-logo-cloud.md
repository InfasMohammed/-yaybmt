# Brands page LogoCloud

The client-supplied interactive LogoCloud replaces the simple /brands/ directory grid. It uses all nine genuine YAYBMT brand records, their unchanged /brand/.../ links and seven existing local logo assets. Marine Locks and Marine Sanitary Fittings use text wordmarks only, with no substitute images. The visible title, metadata, canonical and page URL are unchanged.

The supplied bordered grid, faint mesh, cursor spotlight, decorative corner marks and restrained logo tilt are adapted to the charcoal/off-white/copper palette. No NVIDIA/Supabase/demo logos, invented technical tags or distributor claims are included. KOPAT's recorded distributor badge remains visible in copper/white. Brand names and product links stay visible without hover or JavaScript. Keyboard focus has a clear copper outline. Touch input does not trigger pointer tilt, and reduced-motion preferences disable spotlight/tilt.

Existing React, TypeScript, components/ui and shared CSS infrastructure are reused. The plus decoration needs no icon package, and no dependencies are added. Pointer coordinates use scoped CSS custom properties rather than React state on every mouse movement. The layout uses three desktop columns, two mobile/tablet columns and one at the narrowest widths to keep long names readable.
